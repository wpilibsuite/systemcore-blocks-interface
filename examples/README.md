# Example libraries

Example third party `.blocks_lib` libraries. See `docs/blocks_lib_format.md` for the file format.

| Directory          | Library             | Toolbox categories                               | Components                             | Samples         |
|--------------------|---------------------|--------------------------------------------------|----------------------------------------|-----------------|
| `blocks_lib_demo/` | Blocks Demo Library | Demo Math (with Joystick Helpers), Demo Text     | LimitSwitch, Gripper                   | GripperBot      |
| `field_sensors/`   | Field Sensors       |                                                  | BeamBreak, Bumper, UltrasonicSensor    | SensorBot       |
| `led_effects/`     | LED Effects         | None: its blocks are directly under LED Effects  |                                        |                 |
| `pid_tools/`       | PID Tools           | PID Tuning                                       | SimplePID                              | PidArm          |
| `rev_robotics/`    | REV Robotics        | A301, CIEColor, ColorMatch, ColorSensorV3        | A301, ColorSensorV3                    | DifferentialDrive301, MecanumRobot301 |

Each example has a `metadata.json`, a Python package in `python/`, and `toolboxes/` and/or
`components/` directories. REV Robotics is the REV hardware support that used to be built in to
Blocks: it has no Python package, since its wheel (`robotpy-rev`) is downloaded from the packages in
`requirements.txt`, its `components/` and `python_data/` are generated by
`rev_robotics/generate_python_data.py`, and its `toolboxes/` are generated when it is built from the
classes listed in `python_toolbox.json`. All of them except LED Effects have a sample project in `samples/`, to
show that samples are optional. All of them except PID Tools set a `color`, so you can see how
library colors look in the toolbox, and that `color` is optional. Only Blocks Demo Library is
translated (English and Spanish, in `locales/`), to show that translations are optional.

## Building

```bash
./build.sh                  # builds all of the examples
./build.sh pid_tools        # builds one example
```

Each library is written to `examples/build/<name>.blocks_lib`. 

Building REV Robotics needs an internet connection to download its wheel, 
and `npm install` to generate its toolboxes. 

Upload them using **Manage > Libraries...** in Blocks.
